If-Else Statement in C

The if-else statement in C is used to make decisions based on conditions. It allows the program to execute different blocks of code based on whether a condition is true or false.

1. Basic If-Else Structure

The general syntax of an if-else statement is:

if (condition) {
    // Code to execute if condition is true
} else {
    // Code to execute if condition is false
}

2. Example: Checking Even or Odd

We can use an if-else statement to check if a number is even or odd.

if (num % 2 == 0) {
    printf("The number is even");
} else {
    printf("The number is odd");
}

Here, if the remainder when num is divided by 2 is zero, the number is even; otherwise, it's odd.

3. Nested If-Else Statements

If-else statements can be nested inside one another for more complex decision-making.

if (age >= 18) {
    if (age >= 60) {
        printf("You are a senior citizen");
    } else {
        printf("You are an adult");
    }
} else {
    printf("You are a minor");
}

Here, we first check if the person is 18 or older. If they are, we check again if they are 60 or older to determine if they are a senior citizen.

4. Using Logical Operators in If-Else

Logical operators like && (AND) and || (OR) help combine multiple conditions.

if (temperature >= 30 && humidity >= 70) {
    printf("It's a hot and humid day!");
} else {
    printf("Weather is moderate.");
}

Here:

  • temperature >= 30 checks if it's hot.
  • humidity >= 70 checks if it's humid.
  • Both must be true for it to print "Hot and humid day!"

Similarly, using the || (OR) operator:

if (age < 18 || hasStudentID) {
    printf("Eligible for student discount!");
} else {
    printf("No discount available.");
}

Here, if either the person is under 18 or they have a student ID, they get a discount.

5. Real-World Applications

  • Login Systems: Checking username and password match.
  • Discount Offers: Applying offers based on conditions.
  • Game Logic: Checking player health or game events.
