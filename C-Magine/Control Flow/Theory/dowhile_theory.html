Do-While Loop in C

The do-while loop is a type of loop in C that ensures the loop body executes at least once before checking the condition.

1. Syntax and Working

In a `do-while` loop, the loop body executes first, and then the condition is checked. If the condition evaluates to `true`, the loop continues execution.

do {
    // Code to be executed
} while (condition);

2. Example: Printing Numbers from 1 to 5

The following example prints numbers from 1 to 5 using a `do-while` loop.

int i = 1;
do {
    printf("%d ", i);
    i++;
} while (i <= 5);

3. Flow of Execution

The `do-while` loop executes as follows:

  1. Execute the loop body.
  2. Check the condition.
  3. If the condition is `true`, repeat step 1.
  4. If the condition is `false`, exit the loop.

4. Difference Between `while` and `do-while` Loop

The key difference between `while` and `do-while` loops is:

Feature While Loop Do-While Loop
Execution Order Condition is checked first, then the loop executes. Loop executes first, then the condition is checked.
Guaranteed Execution If the condition is false at the start, the loop may never execute. The loop will always execute at least once.
Use Case Used when the number of iterations is not known beforehand. Used when at least one iteration is required before checking the condition.

5. Example Where `do-while` is Useful

The `do-while` loop is useful when taking user input, ensuring at least one input attempt.

int num;
do {
    printf("Enter a positive number: ");
    scanf("%d", &num);
} while (num <= 0);

6. Real-World Applications

  • Ensuring user input is taken at least once.
  • Displaying menus in applications where an option must be selected.
  • Running a game loop at least once before checking for exit conditions.
  • Simulating repeated tasks such as ATM PIN entry.
