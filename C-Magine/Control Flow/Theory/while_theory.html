While Loop in C

The while loop is a fundamental looping structure in C that allows repeated execution of a block of code as long as a specified condition remains true.

1. Syntax and Working

The `while` loop checks a condition before executing the loop body. If the condition evaluates to `true`, the loop body runs. This process continues until the condition becomes `false`.

while (condition) {
    // Code to be executed
}

2. Example: Printing Numbers from 1 to 5

The following example prints numbers from 1 to 5 using a `while` loop.

int i = 1;
while (i <= 5) {
    printf("%d ", i);
    i++;
}

3. Flow of Execution

The `while` loop executes as follows:

  1. Check the condition.
  2. If the condition is `true`, execute the loop body.
  3. Update the loop control variable.
  4. Repeat steps 1-3 until the condition is `false`.

4. Infinite While Loop

A `while` loop can run infinitely if the condition never becomes `false`. This happens when the loop control variable is not updated properly.

while (1) {
    printf("This loop will run forever!");
}

5. Breaking a While Loop

The `break` statement can be used to exit a `while` loop before the condition becomes `false`.

int i = 1;
while (i <= 10) {
    if (i == 5) { break; }
    printf("%d ", i);
    i++;
}

6. Skipping Iterations with Continue

The `continue` statement is used to skip specific iterations of the loop without exiting completely.

Example: Print numbers from 1 to 5 but skip 3.

int i = 1;
while (i <= 5) {
    if (i == 3) { i++; continue; }
    printf("%d ", i);
    i++;
}

7. Real-World Applications

  • Taking user input until they enter a valid value.
  • Reading a file until the end is reached.
  • Simulating game loops where conditions keep changing dynamically.
  • Performing repetitive calculations like computing factorial.
