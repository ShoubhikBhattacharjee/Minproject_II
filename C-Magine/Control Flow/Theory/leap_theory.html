Leap Year in C

A leap year is a year that has 366 days instead of 365 days. It occurs every four years and is necessary to keep our calendar in alignment with Earth's revolutions around the Sun.

1. Leap Year Logic

A year is considered a leap year if:

  • It is divisible by 4.
  • If it is also divisible by 100, then it should also be divisible by 400 to be a leap year.

2. Understanding the Conditions

To check if a year is a leap year, we use the following conditions:

if (year % 4 == 0) {
    if (year % 100 == 0) {
        if (year % 400 == 0) {
            // Leap year
        } else {
            // Not a leap year
        }
    } else {
        // Leap year
    }
} else {
    // Not a leap year
}

3. Examples

Let's analyze some years:

  • Year 2000: Divisible by 4, 100, and 400 → Leap Year ✅
  • Year 1900: Divisible by 4 and 100, but NOT by 400 → Not a Leap Year ❌
  • Year 2024: Divisible by 4, NOT by 100 → Leap Year ✅
  • Year 2023: NOT divisible by 4 → Not a Leap Year ❌

4. Why Do We Need Leap Years?

The Earth's orbit around the Sun takes approximately 365.2425 days, not exactly 365 days. Without leap years, our calendar would slowly drift out of sync with the seasons. The extra day every four years helps correct this misalignment.

5. Alternative Approach (Using Logical Operators)

Instead of nested if statements, we can use a single-line condition:

if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)) {
    // Leap year
} else {
    // Not a leap year
}

This approach reduces code complexity by combining conditions logically.

6. Real-World Applications

  • Adjusting calendars and scheduling.
  • Handling date-based calculations in software systems.
  • Leap year consideration in financial and astronomical calculations.
