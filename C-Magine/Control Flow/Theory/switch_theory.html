Switch Case in C

The switch case is a control statement used when we need to execute different code blocks based on a specific variable’s value. It is a better alternative to multiple if-else statements when handling many conditions.

1. Syntax and Working

The switch statement works by evaluating an expression and executing the matching case. If no case matches, the default case executes.

switch(expression) {
    case value1:
        // Code block
        break;
    case value2:
        // Code block
        break;
    default:
        // Default code block
}

2. Example: Days of the Week

Let's consider an example where we take an integer input (1-7) and display the corresponding day of the week.

switch(day) {
    case 1:
        printf("Monday");
        break;
    case 2:
        printf("Tuesday");
        break;
    case 7:
        printf("Sunday");
        break;
    default:
        printf("Invalid input");
}

3. Why Use Break?

The break statement is necessary to exit the switch block after a case is executed. Without it, execution will continue into the next case, causing unintended behavior.

4. Default Case

The default case is optional but useful to handle invalid inputs.

5. Limitations of Switch Case

  • Works only with integer and character values.
  • Cannot handle conditions like x > 5 (unlike if-else).
  • Cannot use floating-point numbers or complex conditions.

6. Alternative Approach Using If-Else

If conditions involve relational operators, if-else is a better choice:

if (day == 1) {
    printf("Monday");
} else if (day == 2) {
    printf("Tuesday");
} else {
    printf("Invalid input");
}

7. Real-World Applications

  • Menu-driven programs.
  • Processing user input in embedded systems.
  • Handling keypress events in applications.
