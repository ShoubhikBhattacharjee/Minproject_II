If-Else Ladder in C

The if-else ladder in C is used when multiple conditions need to be checked one after another. It allows the program to evaluate multiple conditions and execute the corresponding block when a condition is met.

1. Syntax of If-Else Ladder

The general structure of an if-else ladder is:

if (condition1) {
    // Code if condition1 is true
} else if (condition2) {
    // Code if condition2 is true
} else if (condition3) {
    // Code if condition3 is true
} else {
    // Code if no condition is true
}

2. Example: Grading System

The following program assigns grades based on marks.

if (marks >= 90) {
    printf("Grade: A");
} else if (marks >= 80) {
    printf("Grade: B");
} else if (marks >= 70) {
    printf("Grade: C");
} else if (marks >= 60) {
    printf("Grade: D");
} else {
    printf("Grade: F (Fail)");
}

Here:

  • If marks ≥ 90, the student gets an A.
  • If marks ≥ 80, they get a B.
  • If marks ≥ 70, they get a C.
  • If marks ≥ 60, they get a D.
  • Otherwise, they fail (F).

3. Difference Between If-Else and If-Else Ladder

If-Else If-Else Ladder
Used for simpler decision-making. Used when multiple conditions must be checked sequentially.
Only one condition is checked. Several conditions are checked one after another.
Example: Checking even or odd. Example: Assigning grades based on marks.

  • Tax Calculation: Applying different tax slabs based on income.
  • Game Mechanics: Determining player rank based on scores.
