For Loop in C

The for loop is one of the most commonly used loop structures in C. It is useful when the number of iterations is known beforehand. It provides a compact way to iterate over a range of values.

1. Syntax and Working

The for loop consists of three parts:

  • Initialization: Sets the starting value of a loop control variable.
  • Condition: Checks if the loop should continue executing.
  • Update: Modifies the loop control variable after each iteration.
for(initialization; condition; update) {
    // Code block
}

2. Example: Printing Numbers from 1 to 5

Consider a simple example where we print numbers from 1 to 5 using a for loop.

for(int i = 1; i <= 5; i++) {
    printf("%d ", i);
}

3. Flow of Execution

The for loop executes in the following order:

  1. Execute the initialization statement.
  2. Check the condition. If true, proceed to step 3; otherwise, exit the loop.
  3. Execute the loop body (code inside the loop).
  4. Execute the update statement.
  5. Repeat steps 2-4 until the condition is false.

4. Nested For Loops

For loops can be nested inside each other. This is useful for working with matrices or patterns.

for(int i = 1; i <= 3; i++) {
    for(int j = 1; j <= 3; j++) {
        printf("* ");
    }
    printf("\n");
}

5. Decrementing For Loop

The loop can also count down instead of up by decrementing the loop control variable.

for(int i = 5; i >= 1; i--) {
    printf("%d ", i);
}

6. Skipping Iterations with continue

Sometimes, you may want to skip specific iterations of the loop using the continue statement.

For example, printing numbers from 1 to 5, but skipping 3:

for(int i = 1; i <= 5; i++) {
    if(i == 3) { continue; }
    printf("%d ", i);
}

7. Real-World Applications

  • Processing arrays and lists.
  • Repeating tasks like summing numbers.
  • Building patterns and tables.
  • Skipping specific conditions in a loop.
