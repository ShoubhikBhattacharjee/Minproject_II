Diamond Pattern in C

The diamond pattern in C is a combination of an increasing and decreasing pyramid pattern. It consists of two triangles, one pointing upwards and the other downwards, creating a diamond shape.

Understanding the Structure

The diamond pattern is printed in two halves:

  • Upper Half: Forms a pyramid with increasing stars.
  • Lower Half: Forms an inverted pyramid with decreasing stars.

Logic to Print a Diamond Pattern

The approach involves nested loops:

for (int i = 1; i <= n; i++) { // Upper half
    Print spaces;
    Print stars;
}
for (int i = n-1; i >= 1; i--) { // Lower half
    Print spaces;
    Print stars;
}

Example Output

                *    
               ***   
              *****  
             ******* 
              *****  
               ***   
                *

Important Considerations

  • The number of spaces before the stars decreases in the first half and increases in the second half.
  • The number of stars increases up to the center row and then decreases symmetrically.
  • Using nested loops efficiently can optimize pattern printing.
