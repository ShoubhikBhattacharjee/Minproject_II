Right-Triangular Pyramid Pattern in C

A right-triangular pyramid is a pattern consisting of stars (*) arranged in a triangular shape. The number of stars increases with each row, forming a right-angled triangle.

1. Understanding the Pattern

The pattern looks like this for n = 5:

*
**
***
****
*****

2. Logic Behind the Pattern

To print this pattern, we use:

  • A nested loop: The outer loop controls the rows, while the inner loop prints stars.
  • The number of stars in each row equals the row number.

3. Code Logic

The logic can be implemented using a nested for loop:

for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= i; j++) {
        printf("*");
    }
    printf("\n");
}

4. Explanation of Code

The outer loop runs from 1 to n (number of rows), and for each row:

  • The inner loop runs from 1 to i, printing i stars.
  • A newline character \n is used to move to the next line.

5. Applications of Patterns

  • Used in game development for graphical representations.
  • Helps in understanding loops and nested loops.
  • Useful in designing UI components like loading indicators.
