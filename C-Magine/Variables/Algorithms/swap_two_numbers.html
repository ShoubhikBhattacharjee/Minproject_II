Swapping 2 Numbers Algorithm

Step 1:
Start the program, including necessary header files and the 'main' function.
Step 2:
Declare the variables -
int a = 5, b = 10, temp;
Step 3:
Display values of variables 'a' and 'b' before swapping.
Step 4:
Assign 'temp' = 'a'.
Step 5:
Assign 'a' = 'b'.
Step 6:
Assign 'b' = 'temp'.
Step 7:
Display values of variables 'a' and 'b' after swapping.
Step 8:
End the program.
