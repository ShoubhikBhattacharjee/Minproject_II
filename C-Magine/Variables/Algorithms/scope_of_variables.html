Swapping 2 Numbers Algorithm

Step 1:
Start the program, including necessary header files and the 'main' function.
Step 2:
Declare global variable -
int globalVar = 10;
Step 3:
Enter 'main' function.
Step 4:
Call 'demoFunction()' function.
Step 5:
Declare Variables -
int localVar = 5;
static int staticVar = 0;
Step 6:
Increment 'staticVar' by 1.
Step 7:
Display 'localVar', 'staticVar', 'globalVar'.
Step 8:
Return to 'main' function.
Step 9:
Call 'demoFunction()' function.
Step 10:
Declare Variables -
int localVar = 5;
static int staticVar = 0;
Step 11:
Increment 'staticVar' by 1.
Step 12:
Display 'localVar', 'staticVar', 'globalVar'.
Step 13:
Return to 'main' function.
Step 14:
End the program.
