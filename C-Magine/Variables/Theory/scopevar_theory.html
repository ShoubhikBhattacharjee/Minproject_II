Scope of Variables in C

In C, the scope of a variable defines the region of the program where the variable can be accessed and modified.

1. Local Variables

Definition: Local variables are declared inside a function or block ({ }) and are only accessible within that function or block.

  • Created when the function is called and destroyed when it exits.
  • Stored in the stack memory.
  • Have garbage values if not initialized.
#include <stdio.h>
void function() { int a = 10; // Local variable printf("Local variable a: %d\n", a); } int main() { function(); // Calling the function printf("%d", a); // Error! 'a' is not accessible here return 0; }

2. Global Variables

Definition: A global variable is declared outside all functions and is accessible from any function in the program.

  • Stored in the data segment of memory.
  • Retains its value throughout execution.
  • Default value is 0 if not initialized.
#include <stdio.h> int g = 20; // Global variable void function1() { printf("Global variable g in function1: %d\n", g); } void function2() { g = 30; // Modifying global variable printf("Global variable g in function2: %d\n", g); } int main() { function1(); function2(); function1(); // The value remains modified return 0; }

3. Static Variables

Definition: A static variable retains its value even after the function exits.

#include <stdio.h> void counter() { static int count = 0; // Static variable count++; printf("Counter: %d\n", count); } int main() { counter(); // Output: 1 counter(); // Output: 2 counter(); // Output: 3 return 0; }

4. Register Variables

Definition: A register variable is stored in CPU registers for faster access.

#include <stdio.h> void function() { register int i = 5; // Register variable printf("Register variable: %d\n", i); // printf("%p", &i); // Error! Cannot get address of register variable } int main() { function(); return 0; }

Summary Table

Variable Type Scope Lifetime Storage Location Default Value
Local Inside a function/block Until function ends Stack Garbage
Global Entire program Until program ends Data Segment 0 (if not initialized)
Static (Local) Inside a function Retains value across calls Data Segment 0
Static (Global) Only within the same file Until program ends Data Segment 0
Register Inside a function/block Until function ends CPU Register (if available) Garbage

Conclusion

Understanding variable scope helps in:

  • Memory management – Avoiding unnecessary memory usage.
  • Controlling access – Restricting or allowing access where needed.
  • Performance optimization – Using register for fast access.
  • Preventing side effects – Avoiding unintended modifications with global variables.
