2D Array Initialization in C

In C, a 2D array is an array of arrays that can be used to store tabular data. It is declared and initialized in various ways.

1. Declaring a 2D Array

A two-dimensional array is declared using the following syntax:

data_type array_name[rows][columns];

For example:

int matrix[3][3];

2. Initializing a 2D Array

2D arrays can be initialized at the time of declaration:

int matrix[3][3] = { {1, 2, 3}, {4, 5, 6}, {7, 8, 9} };

Alternatively, values can be assigned individually:

matrix[0][0] = 1; matrix[0][1] = 2; matrix[0][2] = 3;

3. Accessing Elements

Elements in a 2D array are accessed using row and column indices:

printf("%d", matrix[1][2]); // Accesses element at row 1, column 2

4. Printing a 2D Array

A nested loop is typically used to print the contents of a 2D array:

for(int i = 0; i < 3; i++) { for(int j = 0; j < 3; j++) { printf("%d ", matrix[i][j]); } printf("\n"); }

5. Importance of 2D Arrays

2D arrays are widely used in applications such as:

  • Matrix operations
  • Graph representations
  • Game development (e.g., tic-tac-toe, chess)
  • Image processing
