Functions in C

1. Introduction

A function in C is a block of reusable code that performs a specific task. Functions improve modularity, readability, and reusability of code.

2. Why Do We Need Functions?

  • ✔ Avoids repetition of code.
  • ✔ Makes the program more organized.
  • ✔ Easier to debug and maintain.
  • ✔ Helps in modular programming.

3. Types of Functions

Function Type Description
Library Functions Predefined functions in C (e.g., printf(), scanf(), sqrt()).
User-Defined Functions Functions created by the programmer.

4. Function Syntax

A function in C follows this structure:

return_type function_name(parameters) {
    // Function body
    return value;
}

5. Function Declaration (Prototype)

A function must be declared before use (if defined later in the file). This is called a function prototype. 

int add(int, int); // Function declaration

6. Function Definition

The actual implementation of the function.

int add(int a, int b) {
    return a + b;
}

7. Function Call

A function is executed when called inside main().

int sum = add(5, 3); // Calling the function

8. Function Call Types

Call Type Description
Call by Value Copies the actual value; changes inside the function do not affect the original variable.
Call by Reference Passes address; changes inside the function reflect in the original variable.

9. Example: Addition of Two Numbers

The following program adds two numbers using functions:

#include <stdio.h>

int add(int a, int b); // Function declaration

int main() {
    int num1 = 10, num2 = 20;
    int result = add(num1, num2); // Function call
    printf("Sum = %d", result);
    return 0;
}

int add(int a, int b) { // Function definition
    return a + b;
}

10. Advantages of Functions

  • ✔ Reduces code duplication.
  • ✔ Makes debugging easier.
  • ✔ Enhances readability.
  • ✔ Promotes modular programming.

11. Conclusion

Functions play a key role in C programming by breaking large programs into smaller, manageable blocks. They enhance efficiency, readability, and reusability, making programming more structured.
