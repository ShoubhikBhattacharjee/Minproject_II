Call by Value & Call by Reference in C

1. Introduction

In C programming, when we pass arguments to a function, there are two main ways to do it:

  • Call by Value: The function gets a copy of the variable’s value.
  • Call by Reference: The function gets a reference (memory address) of the variable.

2. Call by Value

In Call by Value, a copy of the actual variable is passed to the function. Any changes made inside the function do not affect the original variable.

Key Characteristics:

  • A copy of the variable is created.
  • Changes inside the function do not affect the original variable.
  • Memory address of the original variable is not passed.

Example:

void modify(int a) {
    a = a + 10;  // This change won't affect the original variable
}

3. Call by Reference

In Call by Reference, a function receives the memory address of the actual variable. Any changes made inside the function will reflect in the original variable.

Key Characteristics:

  • Memory address of the variable is passed.
  • Changes inside the function directly affect the original variable.
  • Uses pointers to access memory.

Example:

void modify(int *a) {
    *a = *a + 10;  // This change affects the original variable
}

4. Comparison Table

Feature Call by Value Call by Reference
Parameter Type Copy of the variable Memory address of the variable
Changes Affect Original? No Yes
Memory Usage More (creates copies) Less (uses existing memory)
Performance Slower for large data Faster for large data
Used For Simple data types Arrays, large structures

5. When to Use Which?

  • Use Call by Value when you do not want to modify the original value.
  • Use Call by Reference when changes to the variable should persist outside the function.

6. Example: Swapping Two Numbers

Consider swapping two numbers using both methods:

❌ Call by Value (Fails to Swap)

void swap(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

The original values remain unchanged.

✔ Call by Reference (Successfully Swaps)

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

This successfully swaps values using pointers.

7. Conclusion

  • Call by Value is safe but inefficient for large data structures.
  • Call by Reference is powerful but requires knowledge of pointers.
