Recursion in C

1. Introduction

Recursion is a programming technique where a function calls itself to solve smaller instances of a problem until a base condition is met.

2. How Recursion Works?

When a function calls itself, a new execution context is created for each function call. These calls stack up in memory and are resolved in reverse order once the base condition is met.

3. Structure of a Recursive Function

A recursive function typically follows this structure:

return_type function_name(parameters) {
    if (base_condition) {
        return result;
    } else {
        return function_name(modified_parameters);
    }
}

Here:

  • Base Condition: The terminating condition to stop recursion.
  • Recursive Case: The function calls itself with a modified argument.

4. Example: Factorial Using Recursion

The factorial of a number n (denoted as n!) is calculated as: 

n! = n × (n-1) × (n-2) × ... × 1

Using recursion, factorial can be defined as:

factorial(n) = n × factorial(n-1)  (if n > 1)
factorial(1) = 1  (Base Case)

5. Recursive Function Execution (Step-by-Step)

For factorial(4), the function calls occur in this order: 

factorial(4) → 4 × factorial(3)
factorial(3) → 3 × factorial(2)
factorial(2) → 2 × factorial(1)
factorial(1) → 1  (Base Case Reached)

Then, the functions start resolving in reverse order: 

factorial(2) = 2 × 1 = 2
factorial(3) = 3 × 2 = 6
factorial(4) = 4 × 6 = 24

6. Types of Recursion

Type Description
Direct Recursion Function calls itself directly.
Indirect Recursion Function A calls Function B, which calls Function A.
Tail Recursion Recursive call is the last statement in the function.
Head Recursion Recursive call happens first before other operations.

7. Recursive vs. Iterative Approach

Approach Advantages Disadvantages
Recursion ✔ Simpler and elegant solution. ✘ Uses more memory (function calls stored in stack).
Iteration (Loops) ✔ Efficient in memory usage. ✘ Sometimes harder to implement.

8. Key Points About Recursion

  • ✔ Recursion is useful for problems like factorial, Fibonacci series, tree traversal, and backtracking algorithms.
  • ✔ Every recursive function must have a base condition to avoid infinite loops.
  • ✔ Recursive functions consume more stack memory, so deep recursion can cause stack overflow.

9. Conclusion

Recursion is a powerful tool in C programming that simplifies problems by breaking them into smaller instances. However, it should be used carefully to avoid excessive memory usage.
