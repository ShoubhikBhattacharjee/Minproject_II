Swapping 2 Numbers Algorithm

Step 1:
Start the program, including necessary header files and the 'main' function.
Step 2:
Enter 'main' function.
Step 3:
Declare variables -
int a = 5, b = 5;
Step 4:
Call function ‘increment_by_value(a)’.
Step 5:
Call ‘factorial()’ function passing ‘num’ as the parameter.
Step 6:
Store ‘a’ as formal parameter ‘x’.
Step 7:
Increment 'x' by 1.
Step 8:
Return 'x'.
Step 9:
Return to 'main' function.
Step 10:
Store returned value in variable 'result1'.
Step 11:
Display 'result'.
Step 12:
Call function ‘increment_by_reference(&b)’.
Step 13:
Store ‘&b’ as formal parameter ‘*x’.
Step 14:
Increment '*x' by 1.
Step 15:
Return to 'main' function.
Step 16:
Display 'a', 'result1' and 'b'.
Step 17:
End the program.
