Swapping 2 Numbers Algorithm

Step 1:
Start the program, including necessary header files and the 'main' function.
Step 2:
Enter 'main' function.
Step 3:
Declare variable -
int num;
Step 4:
Take input for 'num' from the user.
Step 5:
Call 'factorial()' function passing 'num' as the parameter.
Step 6:
Store 'num' as the formal parameter 'n'.
Step 7:
If n == 1,
    Go to step .
else
    Go to step 8.
Step 8:
Call ‘factorial()’ function passing ‘n - 1’ as parameter.
Step 9:
Store ‘n - 1’ as formal parameter ‘n’.
Step 10:
Go back to step 7.
Step 11:
Display 'result'.
Step 12:
End the program.
