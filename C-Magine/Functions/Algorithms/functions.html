Swapping 2 Numbers Algorithm

Step 1:
Start the program, including necessary header files and the 'main' function.
Step 2:
Enter 'main' function.
Step 3:
Declare variables -
int x, y, result;
Step 4:
Take inputs for 'x' and 'y' from the user.
Step 5:
Call 'add()' function passing 'x' and 'y' as parameters.
Step 6:
Store 'x' and 'y' as formal parameters 'a' and 'b'.
Step 7:
Declare variable 'sum' and store 'a + b' in 'sum'.
Step 8:
Return 'sum'.
Step 9:
Return to 'main' function.
Step 10:
Store returned value in variable 'result'.
Step 11:
Display 'result'.
Step 12:
End the program.
