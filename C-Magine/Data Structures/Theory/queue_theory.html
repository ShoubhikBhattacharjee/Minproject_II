Queue ADT in C

1. Introduction

A queue is a linear data structure that follows the FIFO (First In, First Out) principle, meaning the element added first will be removed first.

2. Why Do We Need Queues?

  • ✔ Used in CPU Scheduling and Process Management.
  • ✔ Helps in managing multiple requests (e.g., printer queue, call center system).
  • ✔ Used in data buffering (e.g., video streaming, packet transfer in networking).
  • ✔ Maintains order of execution in real-world scenarios.

3. Concept of Queue

In a queue:

  • Enqueue → Insert an element at the rear.
  • Dequeue → Remove an element from the front.
  • Queue follows FIFO (First In, First Out) order.

Example: Real-World Analogy

Think of a queue in a supermarket where customers line up at the billing counter.

✔ The first person to stand in line will be served first.
✔ A new customer joins at the rear of the queue.
✔ Customers leave the queue from the front.

4. Queue Operations

Operation Description
Enqueue Insert an element at the rear.
Dequeue Remove an element from the front.
Peek Get the front element without removing it.
IsEmpty Check if the queue is empty.
IsFull Check if the queue is full.

5. Example Execution

Consider inserting 10, 20, 30, 40 into a queue:

Initial Queue: Empty

Enqueue(10) → [10]

Enqueue(20) → [10, 20]

Enqueue(30) → [10, 20, 30]

Dequeue() → Removes 10 → [20, 30]

Front Element: 20

6. Types of Queues

  • ✔ Simple Queue – Basic FIFO structure.
  • ✔ Circular Queue – Connects rear to front for efficient space use.
  • ✔ Priority Queue – Elements are dequeued based on priority.
  • ✔ Deque (Double-Ended Queue) – Insertion and deletion can happen at both ends.

7. Advantages of Queues

  • ✔ Helps in managing data efficiently.
  • ✔ Used in real-world applications like task scheduling.
  • ✔ Supports different variations like circular and priority queues.

8. Conclusion

Queues are an essential data structure used for task scheduling, buffering, and sequential processing. Their ability to maintain an ordered process makes them highly useful in many computing applications.
