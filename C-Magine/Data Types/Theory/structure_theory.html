Structures in C

A structure in C is a user-defined data type that groups variables of different types under a single name.

1. Why Use Structures?

  • Grouping Related Data: Unlike arrays, structures store multiple data types together.
  • Code Organization: Makes complex programs more readable and manageable.
  • Memory Optimization: Helps in better memory utilization.

2. Structure Syntax

        struct Student {
            char name[50];
            int age;
            float marks;
        };

3. Declaring and Initializing Structures

        struct Student s1;  // Declaration
        struct Student s2 = {"John", 20, 85.5}; // Initialization

4. Accessing Structure Members

        strcpy(s1.name, "Alice");
        s1.age = 22;
        s1.marks = 90.0;

5. Example: Student Record

        #include <stdio.h>
        #include <string.h>
        struct Student {
            char name[50];
            int age;
            float marks;
        };
        int main() {
            struct Student s1;
            strcpy(s1.name, "Alice");
            s1.age = 22;
            s1.marks = 90.5;
            printf("Name: %s\nAge: %d\nMarks: %.2f\n", s1.name, s1.age, s1.marks);
            return 0;
        }

6. Memory Allocation in Structures

Each structure member takes space in memory according to its data type. For example:

        struct Data {
            char c;   // 1 byte
            int x;    // 4 bytes
            float y;  // 4 bytes
        };

Total size depends on memory alignment.

7. Nested Structures

A structure inside another structure is called a nested structure.

        struct Address {
            char city[20];
            int pin;
        };
        struct Employee {
            char name[50];
            struct Address addr;
        };

8. Structures with Pointers

We can use pointers with structures.

        struct Student s1, *ptr;
        ptr = &s1;
        ptr->age = 21; // Using arrow operator

9. Difference Between Structure and Union

Feature Structure Union
Memory Allocation Each member gets separate memory All members share the same memory
Size Sum of all members’ sizes Size of the largest member
Usage Used for storing related data Used for memory-efficient programs

10. Real-World Applications

  • Databases: Storing employee, student, or customer details.
  • Game Development: Managing player statistics.
  • Operating Systems: Handling process control blocks.
  • Banking System: Maintaining account records.

11. Dynamic Memory Allocation in Structures

        struct Student *s1;
        s1 = (struct Student*) malloc(sizeof(struct Student));
        strcpy(s1->name, "John");
        s1->age = 20;
        printf("Name: %s, Age: %d", s1->name, s1->age);
        free(s1); // Free memory
