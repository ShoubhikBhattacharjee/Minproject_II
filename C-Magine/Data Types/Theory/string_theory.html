Strings in C

A string in C is an array of characters terminated by a null character ('\0'). Unlike other languages, C does not have a built-in string data type, so we use character arrays or pointers.

1. Declaring and Initializing Strings

Strings can be initialized in two ways:

char str1[] = "Hello"; // String using array
char str2[] = {'H', 'e', 'l', 'l', 'o', '\0'}; // Manual null-terminated string
char *str3 = "Hello"; // String as a pointer

2. Reading and Printing Strings

Use scanf() and printf():

char name[20];
scanf("%s", name); // Reads a word (no spaces)
printf("Hello, %s", name); // Prints the string

3. Common String Functions (string.h)

To manipulate strings, use the <string.h> library.

Function Description Example
strlen() Returns length of a string. strlen("Hello") → 5
strcpy() Copies one string to another. strcpy(dest, src)
strcat() Concatenates (joins) two strings. strcat(str1, str2)
strcmp() Compares two strings. strcmp("abc", "xyz") → Negative
strrev() Reverses a string. strrev("Hello") → "olleH"

4. Example Program

This example demonstrates string functions:

#include <stdio.h>
#include <string.h>

int main() {
    char str1[20] = "Hello";
    char str2[20] = " World";

    printf("Length of str1: %lu\n", strlen(str1));
    strcat(str1, str2);
    printf("Concatenated: %s\n", str1);
    return 0;
}

5. String Comparison

Use strcmp():

if (strcmp(str1, str2) == 0) {
    printf("Strings are equal");
} else {
    printf("Strings are different");
}

6. Real-World Applications

  • Text Processing: Search, replace, formatting.
  • Data Storage: Storing user inputs, logs, and file data.
  • Cryptography: Encrypting and decrypting text.
