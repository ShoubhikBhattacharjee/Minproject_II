Structures in C

In C, a structure is a user-defined data type that allows grouping of variables of different types under a single name. It is used to represent complex data types like records.

1. Declaring a Structure

A structure is declared using the struct keyword:

struct Student {
    char name[50];
    int age;
    float marks;
};

2. Creating Structure Variables

We can create structure variables in two ways:

  • Inside the structure definition
  • Outside the structure definition
struct Student s1; // Creating a structure variable

3. Accessing Structure Members

Members of a structure are accessed using the dot (.) operator:

s1.age = 20;
s1.marks = 85.5;

4. Example Program

Below is a complete example of using structures in C:

#include <stdio.h>

struct Student {
    char name[50];
    int age;
    float marks;
};

int main() {
    struct Student s1 = {"Alice", 20, 88.5};
    printf("Name: %s\n", s1.name);
    printf("Age: %d\n", s1.age);
    printf("Marks: %.2f\n", s1.marks);
    return 0;
}

5. Structure Arrays

We can use arrays of structures to store multiple records.

struct Student students[3];

6. Real-World Applications

Structures are widely used in real-world applications:

  • Database Management: Storing records of employees, students, etc.
  • Game Development: Storing player information, scores, etc.
  • Networking: Storing packet headers and connection details.
  • Operating Systems: Managing process control blocks.
