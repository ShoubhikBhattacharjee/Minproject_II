Pointers in C

A pointer is a variable that stores the memory address of another variable. Pointers allow us to manipulate memory directly, improving efficiency and flexibility.

1. Declaring a Pointer

Pointers are declared using the * operator:

int *ptr; // Declaring an integer pointer

2. Assigning Address to a Pointer

Use the & (address-of) operator to assign a variable's address to a pointer:

int x = 10;
int *ptr = &x;

3. Accessing Value using a Pointer

Use the * (dereference) operator to access the value stored at the memory address:

printf("%d", *ptr); // Output: 10

4. Example Program

Below is a complete example demonstrating pointers in C:

#include <stdio.h>

int main() {
    int x = 20;
    int *ptr = &x;
    printf("Value of x: %d\n", x);
    printf("Address of x: %p\n", &x);
    printf("Pointer stores: %p\n", ptr);
    printf("Value via pointer: %d\n", *ptr);
    return 0;
}

5. Pointer Arithmetic

Pointers support arithmetic operations like increment and decrement.

ptr++; // Moves to the next memory address

6. NULL Pointer

A NULL pointer does not point to any valid memory location.

int *ptr = NULL;

7. Pointers to Pointers

A pointer can store the address of another pointer.

int **ptr2 = &ptr;

8. Dynamic Memory Allocation

Pointers are essential for dynamic memory allocation using malloc, calloc, and free.

int *ptr = (int*)malloc(sizeof(int));

9. Real-World Applications

Pointers are widely used in:

  • Memory Management: Dynamic memory allocation.
  • Data Structures: Used in linked lists, trees, etc.
  • Function Pointers: Callbacks and event handling.
  • System Programming: Direct hardware interaction.
