Palindrome Checking in C

A Palindrome is a word, phrase, number, or sequence that reads the same backward as forward. Examples include:

  • Strings: "madam", "racecar", "level"
  • Numbers: 121, 1331, 12321

1. Checking if a String is a Palindrome

To determine if a string is a palindrome, we compare it with its reversed version.

🔹 Using Character Comparison

One way to check is by iterating from both ends of the string and comparing characters.

for(int i = 0, j = strlen(str) - 1; i < j; i++, j--) {
    if(str[i] != str[j]) {
        // Not a palindrome
    }
}

Here, we use two variables: i starts from the beginning, and j starts from the end. If any mismatch occurs, it's not a palindrome.

2. Checking if a Number is a Palindrome

A number is a palindrome if its reverse is equal to the original number.

🔹 Reversing a Number

To reverse a number, we extract its digits and reconstruct the number in reverse order.

while (num > 0) {
    rem = num % 10;
    rev = rev * 10 + rem;
    num /= 10;
}

We extract the last digit using modulus (%), then build the reversed number by multiplying the current reverse by 10 and adding the extracted digit.

3. Using Built-in Functions

Some C libraries provide functions like strrev() for reversing strings.

strcpy(rev, str);
strrev(rev);
if(strcmp(str, rev) == 0) {
    // It's a palindrome
}

Here, we first copy the original string, reverse it, and use strcmp() to compare both.

4. Real-World Applications

  • Data Validation: Ensuring symmetric sequences.
  • Genetics: Palindromic DNA sequences.
  • Cryptography: Symmetric encryption techniques.
