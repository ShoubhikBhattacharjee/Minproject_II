Quick Sort in C

1. Introduction

Quick Sort is a divide and conquer sorting algorithm that works by selecting a pivot element, partitioning the array around the pivot, and then recursively sorting the left and right subarrays. It is one of the fastest sorting algorithms, with an average time complexity of O(n log n).

2. How Does Quick Sort Work?

Quick Sort follows these steps:

  • ✔ Select a pivot element from the array.
  • ✔ Partition the array so that elements smaller than the pivot are on the left, and greater elements are on the right.
  • ✔ Recursively apply Quick Sort to the left and right subarrays.

3. Visual Representation

4. Quick Sort Logic

The key operation in Quick Sort is partitioning:

    int partition(int arr[], int low, int high) {
        int pivot = arr[high]; // Selecting the pivot
        int i = (low - 1);
    
        for (int j = low; j < high; j++) {
            if (arr[j] < pivot) { 
                i++;
                swap(&arr[i], &arr[j]); // Move smaller element to left
            }
        }
        swap(&arr[i + 1], &arr[high]); // Place pivot in correct position
        return (i + 1);
    }

The partition function places the pivot in its correct position and ensures smaller elements are to the left, larger ones to the right.

5. Characteristics of Quick Sort

  • Efficient: Works faster than Merge Sort for small or medium-sized arrays.
  • In-place Sorting: Requires less extra memory compared to Merge Sort.
  • Unstable: Does not preserve the order of duplicate elements.
  • Time Complexity:
    • ✔ Best/Average Case: O(n log n)
    • ✔ Worst Case: O(n²) (if poorly implemented with bad pivot selection)

6. Example: Sorting an Array

The following snippet recursively sorts an array using Quick Sort:

    void quickSort(int arr[], int low, int high) {
        if (low < high) {
            int pi = partition(arr, low, high);
            quickSort(arr, low, pi - 1); // Recursively sort left
            quickSort(arr, pi + 1, high); // Recursively sort right
        }
    }

7. When to Use Quick Sort?

  • ✔ Best suited for large datasets with random elements.
  • ✔ Efficient for in-memory sorting.
  • ✔ Not ideal for datasets that are already nearly sorted (may lead to worst-case performance).

8. Conclusion

Quick Sort is one of the most widely used sorting algorithms due to its efficiency and in-place nature. While its worst-case time complexity is O(n²), careful pivot selection (such as choosing the median) helps maintain O(n log n) performance. Understanding Quick Sort is essential for mastering recursion and algorithm optimization, making it a crucial concept in competitive programming and real-world applications.
