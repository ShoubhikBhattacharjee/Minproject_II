Merge Sort in C

1. Introduction

Merge Sort is a divide and conquer sorting algorithm that splits an array into smaller subarrays, sorts them, and then merges them back together. It is known for its efficiency, with a worst-case time complexity of O(n log n), making it much faster than Bubble Sort for large datasets.

2. How Does Merge Sort Work?

Merge Sort follows these steps:

  • ✔ Divide the array into two halves.
  • ✔ Recursively sort each half.
  • ✔ Merge the sorted halves back together.

3. Visual Representation

4. Merge Sort Logic

Merge Sort recursively divides an array and merges sorted subarrays:

    void merge(int arr[], int left, int mid, int right) {
        int n1 = mid - left + 1;
        int n2 = right - mid;
        
        // Temporary arrays
        int L[n1], R[n2];
        
        // Copy data to temp arrays
        for (int i = 0; i < n1; i++)
            L[i] = arr[left + i];
        for (int j = 0; j < n2; j++)
            R[j] = arr[mid + 1 + j];
        
        // Merge the temp arrays back
    }

The merging step ensures elements are combined in sorted order.

5. Characteristics of Merge Sort

  • Stable: Preserves the relative order of equal elements.
  • Divide and Conquer: Breaks the problem into smaller parts and solves them recursively.
  • Time Complexity: O(n log n) in all cases.
  • Space Complexity: Requires extra space for merging.

6. Example: Sorting an Array

The following snippet recursively sorts an array using Merge Sort:

    void mergeSort(int arr[], int left, int right) {
        if (left < right) {
            int mid = left + (right - left) / 2;
            mergeSort(arr, left, mid);
            mergeSort(arr, mid + 1, right);
            merge(arr, left, mid, right);
        }
    }

7. When to Use Merge Sort?

  • ✔ Best for large datasets due to its O(n log n) efficiency.
  • ✔ Useful when stability is required.
  • ✔ Performs well on linked lists since merging is easy.

8. Conclusion

Merge Sort is an efficient and reliable sorting algorithm, especially for large datasets. Its divide and conquer approach ensures optimal performance, making it a fundamental technique in computer science. Though it requires extra memory, its predictable time complexity makes it a preferred choice for sorting linked lists and external sorting scenarios. Learning Merge Sort helps programmers understand recursion, merging, and how to optimize sorting processes.
