Insertion Sort in C

1. Introduction

Insertion Sort is a simple and efficient sorting algorithm that works similarly to sorting playing cards in your hand. It builds the sorted array one element at a time by placing each element in its correct position. It is particularly useful for small datasets and nearly sorted arrays.

2. How Does Insertion Sort Work?

Insertion Sort follows these steps:

  • ✔ Start with the second element (first element is considered sorted).
  • ✔ Compare it with elements in the sorted portion and shift elements to make space.
  • ✔ Insert the element at the correct position.
  • ✔ Repeat for all elements until the entire array is sorted.

4. Insertion Sort Logic

The key idea in Insertion Sort is shifting elements to make space for the new element:

    void insertionSort(int arr[], int n) {
        for (int i = 1; i < n; i++) {
            int key = arr[i]; 
            int j = i - 1;
            
            while (j >= 0 && arr[j] > key) { 
                arr[j + 1] = arr[j]; // Shift larger element right
                j--;
            }
            arr[j + 1] = key; // Insert element at correct position
        }
    }

The inner loop shifts elements that are greater than the key, ensuring the array remains sorted.

5. Characteristics of Insertion Sort

  • Simple and Easy to Implement: Works well for small datasets.
  • Stable: Maintains the relative order of equal elements.
  • Efficient for Nearly Sorted Arrays: Performs in O(n) in best-case scenarios.
  • Time Complexity:
    • ✔ Best Case: O(n) (Already sorted array)
    • ✔ Worst/Average Case: O(n²)

6. Example: Sorting an Array

The following snippet sorts an array using Insertion Sort:

    #include <stdio.h>
    
    void insertionSort(int arr[], int n) {
        for (int i = 1; i < n; i++) {
            int key = arr[i];
            int j = i - 1;
    
            while (j >= 0 && arr[j] > key) {
                arr[j + 1] = arr[j];
                j--;
            }
            arr[j + 1] = key;
        }
    }
    
    int main() {
        int arr[] = {7, 3, 5, 2};
        int n = sizeof(arr) / sizeof(arr[0]);
    
        insertionSort(arr, n);
    
        for (int i = 0; i < n; i++)
            printf("%d ", arr[i]);
        
        return 0;
    }

7. When to Use Insertion Sort?

  • ✔ Best for small datasets where simplicity matters.
  • ✔ Useful for nearly sorted arrays (adaptive sorting).
  • ✔ Not ideal for large datasets due to O(n²) worst-case performance.

8. Conclusion

Insertion Sort is an intuitive and effective sorting algorithm for small and nearly sorted datasets. While it has O(n²) complexity for large inputs, its simplicity and stability make it useful in certain scenarios. It provides a strong foundation for understanding sorting principles and is often used in hybrid sorting algorithms.
